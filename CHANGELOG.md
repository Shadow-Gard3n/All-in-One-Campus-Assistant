# Changelog

All notable changes to OneDesk AI since Milestone 1 are documented here.

## [Milestone 2] - 2026-11-22

### Added
- Implemented multi-department AI query routing and planning.
- Added department-specific AI assistants.
- Integrated Retrieval-Augmented Generation (RAG) for organizational knowledge.
- Added semantic embeddings using BAAI/bge-small-en-v1.5.
- Integrated MongoDB Atlas Vector Search.
- Implemented multi-department response synthesis.
- Added confidence-based clarification and human support escalation.
- Implemented department-specific support queues.
- Added atomic conversation claiming for support agents.
- Implemented AI-assisted refinement of agent responses.
- Added user and support dashboards.
- Added runtime switching between Gemini and Ollama models.
- Added multi-tenant authentication and role-based access control.

### Improved
- Strengthened organization and department-level data isolation.
- Improved handling of queries involving multiple departments.
- Added tracking of pending support conversations.
- Improved the user support resolution workflow.
